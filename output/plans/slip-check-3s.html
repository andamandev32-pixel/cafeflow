เร่งตรวจสลิปให้จบภายใน 3 วินาที

Context

ต้องการให้ตั้งแต่คีออสก์ถ่ายสลิปจนได้ผลตรวจ จบภายใน 3 วินาที วัดจริงบนเครื่อง dev (Ryzen 7 5825U) ด้วย api/src/slip-ocr.js ตัวปัจจุบัน:

ภาพเวลา
สลิปสังเคราะห์สะอาด (data/slips/*, 720–1280px)0.65–0.95 วิ
เฟรม 1920×1080 + noise แบบเว็บแคมจริง2.4–2.5 วิ (และ jsQR ฝั่งเซิร์ฟเวอร์อ่าน QR ไม่ออก)

แยกขั้นของกรณี noise — ตัวช้าไม่ใช่ OCR:

  • jsQR ทั้งเฟรม attemptBoth ที่หาไม่เจอ: ~1.1 วิ (dontInvert ยัง 0.55 วิ) · ถ้าครอปรอบตำแหน่ง QR: 30 ms และอ่านออก
  • cv.encode('png') ภาพ noise: ~0.56 วิ · JPEG q95: 44 ms
  • OCR รับ PNG: 0.97 วิ · รับ JPEG q95: 0.44 วิ (อ่านยอด/เวลา/เลขอ้างอิงถูกเท่ากัน)

คาดหลังแก้: ~0.6–0.8 วิบนเครื่องนี้ · เครื่องเซิร์ฟเวอร์ร้านที่ช้ากว่า 2 เท่ายังไม่เกิน ~1.6 วิ

Changes

1. ส่งภาพเข้า OCR เป็น JPEG แทน PNG — api/src/slip-ocr.js

  • prepForOcr() คืน cv.encode('jpeg', 95) แทน cv.encode('png') (คงขาวดำ+ยืดคอนทราสต์เดิม)

2. ถอด QR เฉพาะจุดที่คีออสก์เห็น — kiosk + server

คีออสก์ถอด mini-QR อยู่แล้วตอนจับภาพอัตโนมัติ (camScan ใน app/js/cf-kiosk-core.js:998) จึงรู้ตำแหน่ง

  • คีออสก์: เก็บ r.location ล่าสุด (ขยายกลับเป็นพิกัดเฟรมเต็มด้วย 1/s) → camSnap ส่งเป็น query ?qr=x,y,w,h ต่อท้าย path ใน CFApi.upload(...) (ไม่ต้องแก้ cf-api.js; ใช้ query แทน multipart field เพราะ req.file() เห็นเฉพาะ field ก่อนไฟล์) ปุ่ม "ถ่ายภาพ" กดเองไม่มี hint → ไม่ส่ง
  • เซิร์ฟเวอร์: read(buf, hint) → ถ้ามี hint: ครอปกรอบนั้น + ขอบ 25% แล้ว jsQR (dontInvert) ไม่เจอ/ไม่มี hint → fallback ทั้งภาพที่ 960px dontInvert (ตัด attemptBoth — คีออสก์เองก็ใช้ dontInvert)
  • เซิร์ฟเวอร์ยังถอด QR เอง — hint เป็นแค่ "ดูตรงไหน" ไม่ใช่ข้อมูลที่เชื่อ (คงหลัก "คีออสก์ส่งแค่ภาพ" ที่ payments.js:149)
  • payments.js route /api/orders/:id/slip: parse req.query.qr (ตัวเลข 4 ค่า, clamp ในขนาดภาพ, ผิดรูป = ไม่ใช้) → ส่งต่อ checkSlip(deps, id, buf, ctx, hint) → slipOcr.read(buf, hint)

3. วัดเวลาแยกขั้น + สคริปต์ benchmark

  • read() คืน stages: { decode, qr, prep, ocr } เพิ่มจาก ms เดิม → เก็บใน ocr_raw (JSON เดิม) และต่อท้าย log [slip] ใน payments.js:369
  • api/scripts/bench-slip.js + npm run bench-slip: รันภาพใน data/slips/** + เฟรมสังเคราะห์ 1920×1080 มี noise พิมพ์เวลาแต่ละขั้นและตรวจว่า CFSlipRules.parse ได้ยอด/เวลา/ref — ใช้ยืนยันเป้า 3 วิบนเครื่องจริงของร้าน

4. เพดานเวลา

  • TIMEOUT_MS 20000 → 8000: ถ้า OCR ค้างผิดปกติ ลูกค้าไม่ต้องยืนรอ 20 วิ (ตกไป REVIEW ตามทางเดิมใน checkSlip)

ไม่ทำในรอบนี้

  • ตรวจบัญชีผู้รับ (พักไว้ก่อน)
  • ครอปตามกรอบเล็ง — หลังข้อ 1–2 ได้เพิ่มน้อย (~0.1–0.2 วิ) แต่เสี่ยงตัดสลิปถ้าลูกค้าถือเบี้ยว
  • worker หลายตัว — จำเป็นเมื่อมีหลายคีออสก์ส่งพร้อมกัน ค่อยทำเมื่อมีคีออสก์ที่ 2
